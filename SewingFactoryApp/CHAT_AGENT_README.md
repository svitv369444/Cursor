# Чат-агент для швейного производства

## Описание

В приложение интегрирован чат-агент, который помогает работникам получать информацию о заданиях, статистике и отвечает на вопросы о работе.

## Функциональность

### Основные возможности:
- 💬 **Чат с агентом** - интерактивное общение с ИИ-помощником
- 📋 **Информация о заданиях** - получение данных о текущем задании
- 📊 **Статистика работы** - просмотр статистики за день
- 👤 **Информация о работнике** - данные о выбранном работнике
- ⏰ **Текущее время** - отображение времени
- ❓ **Справка** - список доступных команд

### Команды для агента:
- "задание" - информация о текущем задании
- "статистика" - статистика за сегодня
- "работник" - информация о текущем работнике
- "время" - текущее время
- "помощь" - показать список команд

## Архитектура

### Компоненты:
1. **ChatActivity** - основной экран чата
2. **ChatViewModel** - управление состоянием чата
3. **ChatAdapter** - отображение сообщений
4. **ChatService** - обработка сообщений агента
5. **ChatMessage** - модель данных сообщения
6. **ChatMessageDao** - работа с базой данных

### Файлы:
- `ChatActivity.kt` - активность чата
- `ChatViewModel.kt` - ViewModel для чата
- `ChatAdapter.kt` - адаптер для RecyclerView
- `ChatService.kt` - сервис обработки сообщений
- `ChatMessage.kt` - модель данных
- `ChatMessageDao.kt` - DAO для базы данных
- `activity_chat.xml` - макет чата
- `item_chat_message.xml` - макет сообщения пользователя
- `item_chat_agent_message.xml` - макет сообщения агента

## Использование

1. На главном экране нажмите кнопку "💬 Чат с агентом"
2. Введите сообщение в поле ввода
3. Нажмите "Отправить" или Enter
4. Агент ответит на ваше сообщение
5. Используйте кнопку "Очистить" для очистки истории чата

## Особенности

- Сообщения сохраняются в локальной базе данных
- Агент понимает контекст (текущий работник, задание, статистика)
- Поддержка различных типов сообщений (текст, информация о задании, статистика)
- Адаптивный интерфейс с разными стилями для сообщений пользователя и агента

## Интеграция

Чат-агент интегрирован в основное приложение и использует:
- Текущего выбранного работника
- Активное задание
- Статистику работника
- Локальную базу данных Room

## Технические детали

- **Минимальная версия Android**: API 24 (Android 7.0)
- **Архитектура**: MVVM с LiveData
- **База данных**: Room
- **UI**: Material Design 3
- **Язык**: Kotlin
